# Workflow Checklist

Use this on every Untrusted<T> task.

## 1. Scope
- Identify milestone from `docs/05-sec4-master-roadmap.md`.
- Define one small deliverable with clear exit criteria.

## 2. Implement
- Change only what is required for the chosen slice.
- Keep interfaces explicit and avoid hidden behavior.

## 3. Verify
- Run the narrowest relevant checks first.
- Run broader checks if subsystem-wide behavior changed.

## 4. Document
- Update relevant docs in `docs/`.
- Add explanation block using the template.

## 5. Closeout
- Summarize what is done vs pending.
- Identify next smallest slice.
