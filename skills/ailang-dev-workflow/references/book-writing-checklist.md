# Book Writing Checklist

Before completing a task, confirm the docs update can be read by someone new to AILang.

- Motivation is stated before implementation details.
- Behavior/spec is explicit and testable.
- At least one concrete example is included.
- Debug/troubleshooting notes are present for non-trivial features.
- Terminology is consistent with existing docs.
- The write-up links naturally with adjacent chapters.
