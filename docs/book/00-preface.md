# 00 Preface

Untrusted<T> is designed for practical backend development with strong safety defaults and explicit behavior.

Project principles for v0.1-lite:
- Keep language ergonomics simple (TypeScript-like surface).
- Keep guarantees explicit (`Option`, `Result`, effects, typed sinks).
- Avoid inheritance/trait complexity in early milestones.
- Build implementation and documentation together.

This book tracks both design and implementation decisions as the compiler evolves.
